# Svelte Code Writer
Use the built-in documentation lookup tools in oh-my-pi to retrieve current Svelte 5 and SvelteKit documentation before writing or modifying .svelte files or .svelte.ts modules.
Always use Svelte 5 Runes syntax ($state, $derived, $props, $effect). Never use the legacy Options API.
